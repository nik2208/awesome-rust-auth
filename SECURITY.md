# Security Policy

## Supported Versions

At the moment, only the latest published crate release and the `main` branch
are considered supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately and do not
open a public issue.

Please send details to **security@awesome-rust-auth.local** and include:

- A clear description of the issue
- Steps to reproduce (or proof of concept)
- Impact assessment
- Suggested remediation (if available)

You can expect an acknowledgment within 72 hours. We will investigate,
coordinate fixes, and disclose responsibly once a patch is available.

## Disclosure Process

- We validate and triage the report
- We develop and test a fix
- We publish a patch release and advisory notes
- We credit reporters (if desired)
